<h1>八部门联合出手，跨境券商遭重创：3000亿资金大撤退，中概股谁接盘？</h1>

<div class="highlight">
<strong>核心提示：</strong>2025年5月22日，中国证监会联合8个部门发布重磅监管文件，富途、老虎、长桥三家互联网券商同日收到行政处罚预告。这意味着长达数年的跨境投资灰色地带被彻底封死，3000万用户、数万亿资产面临大迁移。本文深度解析这一监管风暴的前因后果、三大券商背景、市场影响及投资者应对之策。
</div>

<h2>一、监管铁拳：八部门联合出手，力度前所未有</h2>
<p>2025年5月22日，对于很多跨境投资者来说，是一个标志性的日子。</p>
<p>中国证监会联合8个部门（具体部门未在转录中明确，但如此高规格的联合行动在金融监管史上极为罕见）一起发布了《综合整治非法跨境证券期货基金经营活动实施方案》。这份文件的名称本身就释放了强烈信号：<strong>"综合整治"、"非法"、"跨境"</strong>——三个关键词直指要害。</p>
<p>就在同一天，证监会直接向富途、老虎、长桥三家互联网券商下达了行政处罚预告，写得非常清楚：</p>
<ul>
<li>没收三家机构境内外相关主体的<strong>全部</strong>违法所得</li>
<li>并且依法<strong>从重</strong>处罚</li>
</ul>
<p>注意这两个词：<strong>"全部"和"从重"</strong>。这显然是要动真格的了，不是过去那种"罚酒三杯"的象征性处罚。</p>
<p>这次整治方案划出了非常清晰的红线，明确禁止境外机构在境内做四件事：</p>
<ul>
<li>营销宣传</li>
<li>开户办理</li>
<li>交易指令处理</li>
<li>资金划转</li>
</ul>
<p>翻译成大白话就是：不能做广告拉内地客户，不能帮内地用户开户，不能接受内地用户的买卖指令，也不能帮内地用户转钱进出。这四个环节正是一家跨境券商服务内地客户的完整链条，如今全部被斩断了。</p>

<h2>二、产业链全堵死：不只是境外机构，境内"帮凶"也跑不掉</h2>
<p>这次监管行动的厉害之处在于，它不只是针对境外机构，而是把整个产业链从上到下都给堵死了。</p>
<p>方案同时明确：境内任何主体也不能帮境外机构做配套服务，包括：</p>
<ul>
<li>搭建网站</li>
<li>开发运营交易软件</li>
<li>提供客户服务</li>
</ul>
<p>换句话说，就算你是一家境内的科技公司，只要你给这些境外券商提供技术支持，你也是违法的。这就等于把整个产业链——从获客、开户、交易到技术支持——全部封死，基本没有漏洞可钻。</p>
<p>这种"全产业链打击"的思路，说明监管层这次是做了充分准备的，不是临时起意，而是系统性的顶层设计。</p>

<h2>三、存量用户怎么办：两年过渡期，只能出不能进</h2>
<p>对于已经开了户的内地用户来说，最关心的肯定是：我的账户和资产会怎样？</p>
<p>监管部门设置了一个<strong>两年集中整治过渡期</strong>。官方的说法是"充分保障存量投资者的合法财产权益，给大家足够的缓冲时间"。</p>
<p>在这两年里：</p>
<ul>
<li>你已经开立的账户<strong>不会被强制注销</strong></li>
<li>账户里的资金、股票、基金等资产<strong>也不会被强制清理</strong></li>
</ul>
<p>这两点是明确的，给了投资者一颗定心丸。</p>
<p>但是，账户的功能会被<strong>严格限制</strong>：</p>
<ul>
<li><strong>只能单向卖出交易和资金转出</strong></li>
<li><strong>禁止新增买入</strong></li>
<li><strong>禁止资金转入</strong></li>
</ul>
<p>说白了就是：<strong>只能出，不能进</strong>。你可以慢慢把仓位卖掉，把钱转回来，但不能再加仓，也不能再往里充钱了。</p>
<p>那么两年期满之后呢？三家境外机构必须<strong>全面关停境内网站、交易软件以及所有配套服务</strong>，彻底终止面向境内投资者的一切交易服务。</p>
<p>这意味着，对于存量用户来说，这是一个<strong>倒计时两年的"有序退出"</strong>过程。</p>

<h2>四、不是突然袭击：监管早已布局，只是现在才动手</h2>
<p>很多人说，这件事来得太突然了。但如果你一直有关注跨境投资这个领域，其实这件事是<strong>有迹可循的</strong>，并不是真正意义上的突然袭击。</p>
<p><strong>早在2022年12月</strong>，证监会就已经明确过：境外机构无资质跨境展业属于非法行为。那时候就叫停了老虎、富途等机构的增量开户业务，禁止他们继续在境内招揽新客户。但那次只是禁止新开户，存量用户还能正常使用账户。</p>
<p><strong>到了2025年</strong>，部分境外券商开始想各种办法变相规避监管，通过擦边球的方式继续展业。监管部门发现之后，启动了专项整改督导。</p>
<p>所以这几年一直在收紧，差不多<strong>每隔两三个月就会加高一道门槛</strong>。今年一季度的时候，就算大陆用户专程跑去香港开户也不行了。</p>
<p>这说明，监管层采取了<strong>"渐进式收紧"</strong>的策略：先禁止新增，再限制功能，最后彻底清退。这种"温水煮青蛙"的方式，既给了市场缓冲时间，又避免了系统性风险。</p>

<h2>五、三大券商背景揭秘：腾讯、小米、阿里，谁也保不住</h2>
<p>要理解这件事的影响有多深远，还得看这三家机构的体量和背景。他们可不是普通的小机构，背后各有大树，而且都跟国内顶级互联网巨头有着深度绑定。</p>

<div class="important">
<p><strong>富途证券：</strong></p>
<p>母公司是纳斯达克上市的富途控股，创始团队来自腾讯早期核心员工，腾讯是其核心战略股东。直到最新财报，腾讯仍然持有富途20%的股权。境内业务主要通过深圳子公司承接，是腾讯布局境外证券业务的重要载体。</p>

<p><strong>老虎证券：</strong></p>
<p>同样是纳斯达克上市企业，创始团队来自网易有道，小米集团是重要投资方。IPO前，小米持有老虎证券14.1%的股权。境内业务通过北京子公司开展，依托小米生态的资本和流量做推广。</p>

<p><strong>长桥证券：</strong></p>
<p>香港持牌券商，核心团队大量来自阿里巴巴和蚂蚁集团，典型的阿里系背景。通过浙江子公司服务境内客户，近两年业务增速是三家里面最快的。</p>
</div>

<p>可以看到，三家分别背靠<strong>腾讯、小米、阿里</strong>，都是国内顶级互联网生态向境外延伸的产品。现在这条路被斩断，不只是这三家券商自身的问题，背后牵涉的生态利益也非常复杂。</p>
<p>但即便有这些互联网巨头背书，在金融监管面前，也不得不低头。这说明<strong>金融安全已经上升到了国家战略层面</strong>，任何商业利益都必须让路。</p>

<h2>六、体量大比拼：富途领跑，老虎紧随，长桥增速最快</h2>
<p>从体量上看，富途是毫无疑问的龙头。</p>
<ul>
<li><strong>富途：</strong>2025年全年总营收228.47亿港元（折合大约29亿美元），同比增长将近7成；平台注册用户将近3000万，有资产客户337万；全年总交易量接近15万亿港元，同比增长将近9成。</li>
<li><strong>老虎：</strong>2025年全年总营收6.12亿美元，有资产客户超125万，客户资产规模约6808亿美元，全年总交易量超过1万亿美元。</li>
<li><strong>长桥：</strong>2025年全年名义交易额达1.5万亿美元，全年完成订单5,570万笔，港股交易规模在新兴跨境券商里排第一。</li>
</ul>
<p>这三家加起来，服务的<strong>内地用户数量、托管的客户资产规模以及每年流转的交易体量</strong>，是一个非常惊人的数字。</p>
<p>消息出来之后，富图和老虎的美股<strong>双双暴跌，跌幅超过25%</strong>。这个市场反应其实也侧面说明了一件事：资本对这次政策的解读非常悲观，不觉得影响是一时的。这次处罚和整治方案，对这两家公司的境内业务来说，打击是<strong>根本性的</strong>，基本上就此画上了句号。</p>

<h2>七、市场冲击：3000亿资金大撤退，中概股谁接盘？</h2>
<p>如果我们把视野再放宽一点，这件事的影响其实已经超出了这三家券商本身，延伸到整个中概股市场。</p>
<p>这三家券商的用户，很多人持有的是港股和美股，包括大量的中概股。现在要求存量用户两年内只能卖出，不能买入，这相当于<strong>定向制造了一个持续两年的卖出压力</strong>。</p>
<p>有人估算，两年内从这三家券商流出的资金规模<strong>可能高达约3000亿人民币</strong>。</p>
<p>你想想看：</p>
<ul>
<li>这几年外资本来就在持续撤离中概股</li>
<li>现在通过跨境券商买港美股的那批精英散户，也要被清退了</li>
<li>以后谁来接盘中概股？</li>
</ul>
<p>这是一个很现实的问题：<strong>买家在减少，卖家在增加</strong>。这对持有中概股的朋友来说，是一个需要认真对待的长期风险。</p>
<p>监管层显然也意识到了这个问题，所以在整治方案中提到要"充分保障存量投资者的合法财产权益"。但市场就是市场，政策可以保护资产不被强制清退，但<strong>保护不了股价不下跌</strong>。</p>

<h2>八、投资者应对指南：四步走，从容退出</h2>
<p>说了这么多，最后来说一些比较接地气的判断，供大家参考。那些已经开户的人，现在应该怎么办？</p>

<div class="important">
<p><strong>第一，不要恐慌。</strong></p>
<p>这件事有两年过渡期，你的账户不会明天就注销，资产也不会明天就被冻结。恐慌性的集中抛售，只会让自己在最不利的时候出货，这是对自己最不好的操作。</p>

<p><strong>第二，理解你的资产的 legal 地位。</strong></p>
<p>富途、老虎、长桥这些跨境券商，底层对接的其实都是境外持牌证券机构。你账户里的资产，从法律上来说，是在境外持牌机构托管的。如果这些券商真的要强制给你关户、注销账户，你是可以在香港、新加坡甚至美国的法律框架下告他们的，而且大概率能告赢。强制关户在技术上和法律上都非常困难，代价极大，所以这些券商自己也不会轻易这么做。</p>

<p><strong>第三，两年后能不能完成清退，是个很大的问号。</strong></p>
<p>因为从执行层面来看，难度比较高。存量用户的账户散落在境外持牌机构，不是一纸命令下就能全部关掉的。很多业内人士预测，两年期满之后，这件事大概率会变成一个<strong>灰色地带</strong>，而不是干干净净的完成清退。当然这只是预测，不是什么建议，大家需要自己判断风险。</p>

<p><strong>第四，新开户这条路基本上彻底关了。</strong></p>
<p>如果你现在还没有开户，以后想通过这三家再开一个港美股账户，基本上不可能了。监管方向非常明确：以后合规的境外投资渠道是<strong>港股通、QDII基金、跨境理财通</strong>这些。这个方向只会越来越清晰，但可能也会越来越拥挤。</p>
</div>

<h2>九、正规渠道拥挤：QDII额度告急，跨境ETF溢价高企</h2>
<p>既然灰色渠道被堵死了，那正规渠道呢？问题是，正规渠道也<strong>非常拥挤</strong>。</p>
<ul>
<li><strong>QDII额度有限：</strong>国家外汇管理局目前公布的最新数据，截至2026年4月末，QDII累积批准额度为1761.69亿美元，与3月末持平。而上一轮扩容发生在3月，一次性批了53亿美元，被78家机构瓜分，据上次开闸隔了9个月。关键是额度刚到就被秒光了，53亿美元看起来不少，实际杯水车薪。</li>
<li><strong>跨境ETF溢价高企：</strong>2026年1月，全部跨境ETF加权平均溢价率超过9%。非港股ETF因为QDII的额度卡死，申购窗口长年关闭，二级市场溢价居高不下。以后想买NASDAQ、半导体等热门标的，难度越来越大。</li>
</ul>
<p>随着灰色渠道被彻底切断，QDII产品的一级利（溢价率）大概率继续走高。港股通南下的资金月度可能阶段性放大。</p>
<p>后续QDII的额度会不会扩容？跨境理财通会不会进一步松绑？都值得关注。个人觉得，政策在堵偏门的同时，监管大概率会适当开一些正门的门缝。</p>

<h2>十、深层逻辑：为什么现在出手？汇率、资本外流与金融安全</h2>
<p>很多人可能不理解：为什么监管层要在这个时候出手？毕竟这三家券商已经存在很多年了，为什么偏偏是现在？</p>
<p>要理解这个问题，得从更大的宏观背景来看。</p>
<ul>
<li><strong>楼市下行，</strong>大家不买房，银行信贷放不出去，居民存款还涨到了150多万亿。</li>
<li>监管一直在想让居民存款搬家：搬到楼市，就是支持地方化债；搬到股市，就是支持产业升级。</li>
<li>但股市特别是楼市赚钱效应不好，上万亿民间资金通过灰色渠道把储蓄搬到境外，给对手金融产品接盘，在很多人眼里算是资本外流。</li>
<li>一旦金额大到威胁汇率，那么"个人资产配置自由"就得让位给"整体的金融安全"了。</li>
</ul>
<p>这次八个部门联合出手，构建的是一个<strong>多部门协同、长效常态化</strong>的整治机制。这意味着不是某一个部门偶尔查一次，而是从今往后，有专门的制度在持续盯着。</p>
<p>一句话总结就是：<strong>从过去的"打补丁"升级成了"新制度"，从"劝退"升级成了"直接终节"</strong>。</p>
<p>而要理解这件事影响会有多深远，还得看大方向：<strong>"在美国投资，在中国消费"这条路，官方会持续想办法堵死。这是大方向，大家心里要有数，做好预期管理。</strong></p>

<h2>十一、未来展望：封堵之后，资金会回流A股吗？</h2>
<p>至于这次封堵，是否会像一些人想象的那样，让国内投资美股的资金回流A股？我们就不得而知了，只能说是<strong>拭目以待</strong>。</p>
<p>目前这个时间点也非常微妙：</p>
<ul>
<li><strong>美国有三个万亿级巨头要上市：</strong>包括马斯克的SpaceX、山姆·奥特曼的OpenAI，还有现在红得发紫的Anser Pick。这几个都是美国科技界的巨头，人工智能的未来，在中国非常多粉丝。</li>
<li><strong>中国这边也有两个科技巨头要上市：</strong>一个是合肥国资主导的长鑫存储，一个是武汉国资主导的长江存储，背后都有国家大基金持股，两者市值都有可能破万亿。</li>
</ul>
<p>一边是美国科技巨头上市，一边是中国半导体国家队登场。这场资本博弈，才刚刚开始。</p>
<p>虽然政策指明了三加机构的名字，但肯定不意味着只有这三家机构受到限制。<strong>规定是一视同仁的，所有境外机构在境内开展证券业务，都会受到同样的限制</strong>，只是规模大的先被点名而已。</p>
<p>总的来说，这几年限制境外投资的动作一直在收紧，这次只是力度最大的一次。"在美国投资，在中国消费"这条路，官方会持续想办法堵死。这是大方向，大家心里要有数，做好预期管理。</p>

<div class="conclusion">
<p><strong>结语：</strong></p>
<p>这次八部门联合出手整治非法跨境证券业务，标志着中国资本项目开放的一个阶段性转折。从"有序开放"到"规范开放"，监管的底线越来越清晰：<strong>支持合规渠道，打击灰色地带，维护金融安全。</strong></p>
<p>对于普通投资者来说，这是一个警示：<strong>海外资产配置的需求是真实的，但必须通过合规渠道进行。</strong>灰色渠道或许便利，但政策风险随时可能爆发。在当前的监管环境下，合规成本越来越高，违规代价越来越大。</p>
<p>未来，随着QDII额度扩容、跨境理财通松绑，合规渠道会越来越畅通。但在这个过程中，投资者需要做好<strong>风险管理</strong>：不要恐慌性抛售，不要盲目加仓，要根据自己的风险承受能力和投资目标，制定合理的退出或转换策略。</p>
<p>最后，这件事也提醒我们：<strong>在全球化逆流、地缘政治博弈加剧的当下，资本流动越来越成为国家战略的一部分。</strong>作为普通投资者，我们既要追求资产增值，也要理解政策逻辑，在合规的前提下进行全球资产配置。毕竟，只有合规的，才是可持续的。</p>
